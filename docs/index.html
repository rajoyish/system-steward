System Steward

Your system, with room to breathe.

A terminal app for understanding disk usage, reviewing cleanup targets and running system maintenance on macOS and Windows.

by Rajesh Budhathoki

Install

Homebrew recommended

brew tap rajoyish/system-steward https://github.com/rajoyish/system-steward brew install system-steward

curl needs Python 3.10+

curl -fsSL https://rajoyish.github.io/system-steward/install.sh | sh

Installs into ~/.local/share/system-steward with a launcher in ~/.local/bin. Remove with … | sh -s -- --uninstall.

winget

winget install RajeshBudhathoki.SystemSteward

Scoop

scoop bucket add system-steward https://github.com/rajoyish/system-steward scoop install system-steward

PowerShell

irm https://rajoyish.github.io/system-steward/install.ps1 | iex

Bundles its own Python; nothing else to install. Installs per user, no administrator rights.

Run

system-steward

Open a new terminal after installing. system-steward --help lists options such as --json reports and --keep-awake.

What it does

  • Dashboard: live CPU, memory, disk, network, battery, uptime and top processes.
  • Storage explorer: browse folders by size, search, and export JSON reports.
  • Cleanup: Chrome and Adobe caches, temporary files, developer artifacts and old installers, always previewed before removal.
  • Maintenance: flush DNS, rebuild caches and indexes; Keep Awake to prevent sleep.
